# 北极星打卡官网

静态HTML/CSS/JavaScript落地页，功能与文案以[正式产品说明](../docs/product/产品说明.md)为准。

## 查看与构建

根目录运行 `npm run preview:site`，访问 <http://127.0.0.1:8128/>。页面修改后刷新浏览器。

运行 `npm run build:site`，将 `.build/site/` 作为静态站点根目录即可托管。预览与构建共用固定资源白名单；构建不上传、不发布。

## 产品演示

首屏正放的首页画面提供完整演示。网页体验入口定位到本页该画面，不跳页；主要按钮引导到正式小程序码。它复用 `prototype/`，可以记录、看统计和管理演示项目；演示记录仅存当前页面内存，刷新重置。

统计章节提供受限演示：可切换数量/时间、累计/分布/日历、周/月/年/全部、周期翻页，并点选图表或日历读数；左上角返回禁用，内部不可滚动，不显示记录编辑与设置入口。其余两处产品画面通过 `inert`、禁用指针事件及移除焦点固定展示。390×844画板由ResizeObserver按容器等比缩放。小程序业务源码与真实数据不受影响。

品牌图取自 `images/beijixing.png`；活动图标沿用Phosphor Regular并保留MIT许可。首屏使用一次轻量入场；点击网页体验后，正放的可操作画面短暂闪动蓝色边框，并预览「投篮练习」的打卡成功动效，不新增记录或改变累计值。提示支持重复触发，自动结束且不遮挡点击；编辑过程中不触发成功预览。减少动态效果时关闭入场，并将体验提示改为短暂静态高亮。

分享章节使用同一海报生成器展示阅读单次结果与跳绳累计统计，采用 `preview=poster` 的静态嵌入模式，不展示模拟微信发送按钮。海报及示例数据随原型同步，不另存截图。产品分享口径见[分享结果](../docs/product/分享.md)；文案简要说明常用数量单位、Emoji名称与成功反馈，朋友圈能力保留微信版本条件。
