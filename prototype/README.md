# 北极星打卡交互原型

本目录是当前首版的浏览器演示，正式小程序源码在miniprogram。产品规则见[资料入口](../docs/README.md)，此处只维护打开方式和演示边界，不再重复完整产品说明。

## 使用

在项目根运行 `npm run preview:prototype`：

- [完整交互](http://127.0.0.1:8127/index.html)：记录、搜索、新增/设置、统计、历史编辑删除、整理及成功反馈。
- [多屏总览](http://127.0.0.1:8127/board.html)：首页、单/双项面板、新增、累计/分布/日历和每周/月频率，共用index.html，不维护独立分支原型。

也可离线打开index.html或board.html。VS Code按F5选择完整交互或多屏对照；服务只监听本机，不是后端或外部发布。修改prototype不会同步修改正式WXML/WXSS。

## 演示边界

日期固定2026-11-24，数据在页面内存生成，刷新或「重置示例」恢复；多屏中每个iframe状态独立。新增配置草稿仅当前页面内存保留。不得用原型保存真实个人历史；原型不实现微信用户文件持久化、迁移或生命周期。

「无项目状态」用于演示删除全部项目后的空状态，不代表正式新存档首次进入；正式初始化见[首次使用初始化](../docs/product/首次使用初始化.md)。频率示例中的加油用整数数量记录，不表示支持金额或小数升数。

手机外导航、重置和动效重播为演示外框，不属于产品UI。成功反馈使用本地tsParticles Confetti 4.6.0，56个粒子、首次与再次同强度，原许可证在vendor；未采用引擎不保留。

当前新增庆祝Emoji素材预览，素材池共32种，包含👍、666、💪、🐂🍺、🎉、🎁等庆祝、夸奖图案。手机外「成功反馈素材」可切回已确认的立体彩纸。Emoji使用独立的平面渲染：每轮随机抽取16个不重复的完整图案，相邻两轮至少替换8种、随机排列，少量28～30px主图案与22～24px小图案形成层次，小幅摆角，不压扁/拉斜。评审下拉提供「轻盈散花」（默认推荐，局部快速散开、不同距离分布后缓慢飘落）、「短弧喷泉」（低幅上抛再下落）、「分批跳出」（分散位置分三拍弹出）三种节奏。图案与阴影首次缓存，逐帧仅合成图片，入场与退场平滑过渡，约2.8秒消失。整组以卡片中心成对散开，横向略超出卡片，左右采用相同安全范围，避免边缘保护使动效偏向一侧，配对符号不裁切。彩纸仍为原tsParticles 56片及原有全部参数。流线勾形和轻玻璃蒙版保持一致。该选择不写入项目或草稿，仅用于浏览器原型评审，正式小程序按成功反馈规格交替使用彩纸与已确认的轻盈散花，其他节奏仅供本原型比较。Emoji外观随操作系统字体而异。

微信系统栏、胶囊、键盘和手势均为浏览器模拟；Canvas彩纸不直接移植为正式小程序模块，不承诺与原生WXSS逐帧一致。模拟器与真机验收见[验收规范](../docs/engineering/验收规范.md)。

## 分享流程评审

详情日历按月份实际占用的4／5／6周显示，日期行均匀填满固定高度统计卡片，不保留整行月外空白；切换月份或统计类型不改变卡片高度。月内未来日期仍保留，日期点选读数与分享底栏位置稳定。底层42格日期快照不变，仅浏览器页面展示裁掉整行月外格子。

记录成功提示中的「分享」原地生成图片后直接打开微信图片分享面板的浏览器模拟，不进入中间预览页；累计、分布和日历均在图表卡片右下角使用统一的圆角翻页式「分享」文字入口，项目主题色约9%浅色衬底、可见44×25px、56×44px点击区、12px常规字重、项目主题色文字，不增加底部操作行；项目名后不重复显示分享。日历不显示「少—多」图例。历史记录每条仅保留编辑入口，不提供逐条分享。单次结果仅展示本次投入，右上角为「打卡成功」；有备注自动显示，没有备注不显示备注区域，不提供开关；统计分享保留当前累计／分布／日历、指标与日期范围，日历分享整月视图，不随记录列表的单日筛选变化。累计标为「当前累计」，注明截至日期与本期新增。

海报在浏览器本地生成PNG，「保存图片」实际发起下载。微信朋友／朋友圈面板与相册权限为明确标注的模拟，不发送或发布内容。手机外「分享流程评审」可选择生成失败、低版本微信、相册权限拒绝，再打开预览验证重试与降级。分享不延长约5秒撤销期限；撤销导致原记录变更时，旧预览失效。已有导出的图片是静态副本，后续编辑不会更新它。

直接评审：[打卡结果](http://127.0.0.1:8127/index.html?scene=share-record)、[统计结果](http://127.0.0.1:8127/index.html?scene=share-stats)。浏览器仅模拟微信面板，正式小程序使用原生图片分享接口。

海报使用近白底、项目色光晕与底部淡色弧面、放大核心数值与项目图标；底部右侧使用官方小程序码与居中品牌名，不再放左下品牌标识。去掉口号、记录条数、投入日、重复图表标题和少—多图例。品牌PNG由 images/beijixing.png 等比例缩小。单次结果不显示最近7天、已记录或当天合计；有备注时延长图片，避免覆盖底部。统计海报保留阶梯累计，并标注真实上下界；装饰图形不表示目标、评分或进度。

分享海报原型目前评审右下角官方小程序码方案：使用用户提供的 `miniprogram-code.jpg` 原始JPEG，保留图片自带白底和留边、等比例绘制，不再叠加外层白色圆角底板，移除左下角品牌字标；码与名称作为一组整体上移，码下方留约15px间距，居中显示27px灰色常规字「北极星打卡」，名称基线距底42px，不增加独立Logo或底板；统计海报额外预留底部码区，避免遮挡图表。此方案已同步正式小程序，扫码可用性仍需手机验证。

分享原型与正式小程序统一状态与背景：右上角状态使用浅白胶囊、项目色线性图标（单次为圆圈对勾，统计为柱图）与原状态文案。背景由项目色光晕、半透明折射光带、确定性细纹理和底部弧线组成，单次增加轻星芒，统计装饰集中于图表外，不改变实际数据。
