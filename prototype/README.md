# 北极星打卡交互原型

本目录是当前首版的浏览器演示，正式小程序源码在miniprogram。产品规则见[资料入口](../docs/README.md)，此处只维护打开方式和演示边界，不再重复完整产品说明。

## 使用

在项目根运行 `npm run preview:prototype`：

- [完整交互](http://127.0.0.1:8127/index.html)：记录、搜索、新增/设置、统计、历史编辑删除、整理及成功反馈。
- [多屏总览](http://127.0.0.1:8127/board.html)：首页、单/双项面板、新增、累计/分布/日历和每周/月频率，共用index.html，不维护独立分支原型。

也可离线打开index.html或board.html。VS Code按F5选择完整交互或多屏对照；服务只监听本机，不是后端或外部发布。修改prototype不会同步修改正式WXML/WXSS。

## 演示边界

日期固定2026-11-24，数据在页面内存生成，刷新或「重置示例」恢复；多屏中每个iframe状态独立。新增配置草稿仅当前页面内存保留。不得用原型保存真实个人历史；原型不实现微信用户文件持久化、迁移或生命周期。

「无项目状态」用于演示删除全部项目后的空状态，不代表正式新存档首次进入；正式初始化见[首次使用初始化](../docs/product/首次使用初始化.md)。频率示例中的加油用整数数量记录，不表示支持金额或小数升数。

手机外导航、重置和动效重播为演示外框，不属于产品UI。成功反馈固定使用本地tsParticles Confetti 4.6.0，56片、首次与再次同强度，原许可证在vendor；未采用引擎和方案切换不保留。

微信系统栏、胶囊、键盘和手势均为浏览器模拟；Canvas彩纸不直接移植为正式小程序模块，不承诺与原生WXSS逐帧一致。模拟器与真机验收见[验收规范](../docs/engineering/验收规范.md)。
