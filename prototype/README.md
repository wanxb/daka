# 愚公打卡：交互原型

原型用于评审「记录投入时间与数量」的体验，产品名称为愚公打卡，尚未创建微信小程序业务工程。

## 最新交互

首页为参考提醒事项的88高紧凑卡片，主数值为累计；图表放在项目详情。点击主体记录，点右上角只进详情。

首页顶部使用整行搜索框，placeholder为愚公打卡，按项目名实时筛选，支持清空；无匹配时仍可新增。新增项目取消后自动保留配置草稿，再次新增恢复；创建成功清空草稿及搜索，展示新卡片。新增项目配置草稿在本评审页面内存中保留，刷新仍重置。打卡面板关闭即丢弃未保存输入，再次新建使用项目默认值；编辑历史记录读取原值，不显示续填入口。

输入为一或两个简洁滑块，不显示刻度线或刻度数字，数量按1递增，最后统一点记录；点击数值可精确输入。去掉不记功能，启用的两项均填写有效量；历史空项仍保留。标签与数值同一行，单条高80，滑块触碰区44高。日期收起时底部左侧添加备注、右侧今天日期入口，不显示加号；日期展开时日期/时间组件在上、添加备注文字入口及其输入框在下，收起保留内容。展开后只显示日期、时间，整行均打开系统选择器，不再显示选填及左右滑动提示。

打卡类型为时间、数量两个独立开关，关闭只隐藏配置，重新开启保留内容。范围填写最小/最大，修改边界后默认值自动取整数中点，可手改；日常输入共用配置范围。数量单位默认次，可自定义页/个/字等，首次数量记录后锁定。快速打卡标题不再标注可选。

左侧导航属于原型评审外框，不属于小程序界面。多屏稿中的每一屏有独立演示状态，跨屏不会同步；完整交互请用index.html。

## 演示数据

日期固定为2026-11-24，项目与记录由本地确定性数据生成。可新增、编辑、删除、撤销与修改设置，但只改变当前页面的内存状态；刷新或重置示例还原。

不要把它用于保存真实个人练习历史。它没有实现微信本地文件持久化、账号、云同步或正式数据迁移。开发目录和数据模型以编码前准备包为准。

## 交付范围

- 首页、首次空状态、时间/数量/双项面板。
- 滑轨与圆形滑块、方向键/鼠标拖动、精确输入、折叠备注与整行日期/时间选择。
- 累计/分布图、周期切换、主要指标优先、历史记录编辑删除。详情无添加/补记入口；列表默认5条预览，查看全部后每批20条随主页面滚动追加，支持手动加载、加载完成及收起。
- 项目搜索、新增配置草稿恢复、快速打卡、已有项目设置未保存确认与短时撤销。

HTML的系统栏、微信胶囊、键盘与手势是设计模拟，不代替真实微信UI和真机性能验证。原型代码不能直接当WXML、WXSS或正式仓储实现复制。

详细规则与开发准备：[总览](../docs/predevelopment/README.md)。

时间单位默认分，可选时/秒；在各自分组中设置，卡片、输入、记录与统计跟随所选单位。原始时间统一整秒，换算除不尽显示≈且不写回近似值。两组范围的数值整体右对齐，短横线两侧等距；默认值在修改范围后重算，手动越界结束编辑时限制到对应范围。

新增/设置页使用同一张分组配置卡：时间默认开启，数量默认关闭；单位、范围、默认量随开关展开，不提供数量步长。底部连接主要指标、快速打卡；关闭保留已填值。预览占位名为新的打卡。
