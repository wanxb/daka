# 愚公打卡正式版开发与验证记录

日期：2026-11-24。状态：首版业务代码与本地验证已落地，微信模拟器完整流程及真机验收待完成；未上传、未发布。

## 已实现

- 原生 TS / WXML / WXSS 三页，WebView，自定义安全区导航，AppID `wx181a7d368ae8a4c8`。
- 首页搜索与紧凑双列彩卡；主体打卡、右上独立详情；快速打卡防双击并提供限时撤销。
- 项目名称/图标/颜色；时间、数量独立开关；单位、范围、中点默认值、主要指标；新增原始草稿自动保存及取消恢复。
- 原生滑块按 1 调节；点数值精确输入；日期/时间整行选择；备注独立折叠；关闭不续填。历史近似显示不改原秒数。
- 按项目分别累计时间/数量；累计阶梯线与分布柱图；日/周/月/年/全部；点图读数；历史值和空项保留。
- 记录预览 5 条，全历史 20 条一页；页面滚动加载与手动加载，收起及周期重置；编辑/删除/限时撤销；确认删除项目。
- 文件分片、单写队列、双清单校验与回读、恢复确认、未知版本拒写、删除标记和软容量检查。
- 工具脚本在 CLI 返回 `ok:false` 时输出非零退出码，避免连接超时被 shell 误认为成功。

## 本地验证证据

`npm run check`：TypeScript 检查、33 项 Node 测试、全部正式 TS/WXML/WXSS/JSON 格式检查通过。

测试包括并发与幂等、错误 revision、单位锁定、范围收窄、历史空项、补记重算、闰日及跨年、写入前后故障、冷启动、损坏清单、确认恢复后继续写入、防复活、绝对撤销期限、原始草稿恢复、面板关闭/重开、1 秒精度、快速双击和 126 条记录分页。

长备注测试：2500 条记录、每条 500 个中文字符，按实际 UTF-8 字节拆页；每个封装后页小于 128KiB，冷启动恢复 2500 条。使用内存文件驱动，是协议测试，不是手机性能测量。

`npm run check:native`：使用本机微信工具附带 `wcc.exe` / `wcsc.exe`，8 个 WXML、9 个 WXSS 文件离线语法编译通过。此项不需要连接授权，也不等于整包运行或真机验收。

## 微信环境观察与待办

- 窗口实际显示工具 `2.02.2609250 Stable`、模拟器基础库 `3.18.1`；工程共享配置仍为 `3.0.0`，尚未在最低目标基础库验收。
- 观察到首屏已加载正式搜索与新增卡片，同时出现文件读取错误。console 显示 `readFile:fail .../manifest-b.json not found`，已补适配器兼容并用真实控制器 + 微信回调形状的测试覆盖。
- 热重载期间出现 `<page-container>: Only one instance can exist`；需要完整重新编译后复核，不能把离线编译视为此运行问题已解除。
- CLI 多次返回 `CONNECT_ERROR / wait WechatIDE authorization timeout`，未获得可继续业务的门禁结果。用户反馈看不到请求。
- 当前 Codex 进程为普通权限，微信主进程令牌查询返回 Windows `Access denied (5)`，桌面输入也无可见响应；疑似工具以管理员权限启动。已建议保存编辑后退出工具、以普通权限重新打开，再走正常 CLI 授权。未改安全设置、未读取 Token、未操作授权按钮。
- 后续连接成功后：核对登录/开发者权限 → 整包编译及运行日志 → 新建/记录/重启保留/图表/编辑/分页 → iPhone 与 Android 真机。

## 当前实现边界

当前仓储启动读取并校验整库，内存中保留快照，提交重新分桶；没有实现磁盘游标懒加载、派生缓存或大规模文件索引。页面只发送当前列表批次，不能据此声称整库性能已达标。超过多年月的全部图当前仍按月聚合。

新增草稿、撤销与清单在同一提交中保存，没有独立草稿文件；具体时刻为空用空字符串，持续量空项用 null。时间和数量单位固定规则按领域校验执行。

首版只用本地文件，无云资源、业务网络接口或服务器费用。本地写入恢复不等于换机备份；服务器、同步、导出、地图、金额及深色主题未加入。
