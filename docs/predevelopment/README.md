## 当前技术选择

原生微信小程序，TypeScript/WXML/WXSS，首版WebView；原生slider实现数值调节，详情使用Canvas2D。原始数据保存到本地用户文件，按项目/月分片，不购买服务器、不使用云开发。

普通KV单键1MB、总10MB，本地用户文件与缓存文件共享200MB额度，已读取微信官方正文核对。选择文件方式用于长期积累；内部写入恢复不是手动备份或换机同步。
