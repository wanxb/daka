### 新增与编辑项目文案

新增页布局顺序为项目预览/名称、项目外观、打卡类型和创建按钮。名称为空时预览显示「新的打卡」。

打卡类型使用一张连续白色配置卡：时间组、数量组、主要指标行、快速打卡行。时间、数量、主要指标、快速打卡四个标题统一使用系统字体16号、常规字重400，不加粗；分别配18×18的时钟、数量符号、图表、闪电线性图标，图标不重复参与读屏；标题右侧各有独立开关，新建默认时间开启展开，数量关闭折叠；关闭只隐藏参数，不清理已填内容。开关替换页面内容后保留键盘与读屏焦点。

时间组参数按「时间单位、时间范围、默认时间」排列；数量组按「数量单位、数量范围、默认数量」排列。图标列位于左侧14，宽18，图标与文字间距10；参数文字与四个标题文字统一从42开始，右侧数值对齐。所有分割线从图标右侧的文字起点42开始，图标下方不画线；组内与组间统一这一规则。用分隔线表达同一卡片内的归属，不再用两个横向类型按钮或单独的快捷设置分区。

底部直接连接「主要指标」「快速打卡」两行，去掉首页突出和快速打卡的分区标题。「主要指标」替代「主要累计指标」，开关行名称直接为「快速打卡」。未开启的类型不能选为主要指标，只有一项开启时显示该项；关闭再开启另一项时恢复原本的双项偏好。两项均关闭可保留草稿，创建/保存前提示至少启用一项。

范围只显示左小右大的两个数值，以短横线分隔，最小/最大只作读屏标签。范围输入聚焦时与默认值输入保持相同的无框样式，不显示描边或阴影。输入随等宽数字长度适配，整组靠右，短横线两侧间距相等并垂直居中。修改范围计算整数中点；手动默认值结束编辑后限制到范围内。单位、默认值在分组关闭时保留，恢复不重算。

时间单位按时、分、秒顺序排列，默认分；时间单位与主要指标使用相同的28高扁平按钮，字号12、圆角7，选中用项目色，保持44高的不可见点击区。数量单位默认次，首次数量记录前可编辑，之后固定。卡片、面板、图表读数和列表使用各自项目单位。界面不常驻说明默认值计算或快速打卡规则，需要修正时才就地提示。

新增页取消直接返回，保留名称、打卡类型、颜色、图标、全部快捷配置和快速打卡开关的原始值，再次新增恢复，不弹确认、不额外显示成功提示。草稿不加入首页；创建成功后消费并清空草稿。已有项目设置的未保存确认保持原规则。

## 3. 首页规格

原型基准画板为390×844逻辑像素；也需要覆盖375、430宽及系统文字放大。

顶部不显示「积累」标题，替换为左右对齐卡片区的整行搜索框，最小高度44、圆角13、系统灰色填充，左侧放大镜、右侧按需出现清空按钮。默认不抢焦点、不自动弹键盘。

按项目名实时筛选，不改变原始顺序或累计值；忽略首尾空白、大小写和全半角。输入过程中保留焦点、光标与中文输入法组合状态。空查询显示全部，无匹配提示「没有匹配的项目」，新增入口始终可用；清空保留输入焦点。详情返回、取消新增保留查询；创建成功后清空查询展示新卡片。

| 项目 | 当前起点 |
|---|---|
| 页面左右边距 | 16 |
| 卡片列间/行间距 | 12 |
| 卡片高度 | 88，较大文字时允许增高或转单列 |
| 卡片圆角 | 19 |
| 卡片内边距 | 约14 |
| 图标 | 约24，同一笔画与圆角风格 |
| 累计数值 | 约27，数字等宽，超长值适配 |
| 项目名 | 约15，不能侵占详情入口 |
| 单位与辅助信息 | 约11，不承担唯一关键信息 |
| 详情点击区 | 44×44，视觉图形可更小 |

图标左上，主数值上方靠右，项目名左下，辅助信息右下。首页不同时堆叠今日量、次指标、图表和提示文字。

辅助信息优先级：开启快速打卡时优先显示实际增量；否则双项优先次指标，时间单项可显示分钟余量；剩余空间才显示今日信息。所有关键精确数值在详情可读。

大数量可简写为万等，完整值在详情保留。时间小时与分钟分层表达，10000小时及超长项目名必须纳入排版验收，不能靠无限缩字。

## 4. 记录面板规格

底部面板只保留标题、轻量日期入口、滑动控件、折叠备注和记录按钮。删除「点选即保存」行为；正常面板无论单项双项都统一确认。

两项时面板以约半屏为目标，日期入口移到底部后常规双项状态约398像素高；单个滑动控件高80。备注或日期展开后可以增加高度并滚动，不固定一个永远占满屏幕的大表单。

### 4.1 滑块

- 标签与数值同一行，标签居左、数值和单位居右，数值25号字。
- 使用4高细滑轨、26直径白色圆形滑块与轻阴影；不显示刻度线、刻度数字或中点标签。
- 默认值按配置范围内的真实比例预选，不从最左端动画滑过。
- 数量固定按1递增，不提供步长参数；时间滑动按所选单位的整数调节，合法精确时间不受影响。
- 拖动时滑块连续跟手，显示和草稿量转为有效整数；松手后对齐数值。拖动中不强制跳格，不重建面板。
- 可触碰区域至少44高，支持方向键、Home/End和读屏，点击滑轨也能调节。
- 点当前数值可精确输入；滑动、松手、键盘完成都不提交，最后统一点记录。
- 新记录启用项不能清空，历史空项和未改动的原始秒数不因重绘补值或取整。

### 4.2 日期、时间、备注

日期收起时，滑块下方一行左侧是添加备注，右侧是今天日期入口，替代原加号，不再在标题下方重复显示。两项点击区均至少44高，独立展开；日期展开时，整个日期/时间组件始终先于添加备注文字入口及其输入框，与点击顺序无关。普通打卡面板内可主动展开日期，展开行分别标为日期、时间，不显示选填；点击行内文字、空白或原生字段均打开系统选择器。具体时刻精确到分钟且可以为空，不把保存时刻当开始时间。

底部「添加备注」默认折叠，点开显示多行输入。打卡面板不显示继续上次填写或重新填写，关闭后丢弃未保存内容；再次新建按默认值打开，编辑历史读取原值。已有备注编辑时可以用已填写提示，值仍完整保留。备注最多500字符，长内容可滚动，收起不能清空。

保存按钮使用稳定的「记录」/「保存修改」文案；读屏名称可以包含当次量。普通状态不额外加一串重复数值或营销文案。

## 5. 详情信息层级

1. 项目与全历史累计，主要指标先呈现，双项分开。
2. 指标页签仅在需要时出现，主要指标始终在前；输入面板和记录行同序。
3. 一个图表，累计或分布；日、周、月、年、全部周期。图表类型使用整行均分的分段控件，与下方周期控件左右对齐；类型按钮高32、字号13，选中用白色轻阴影，保留44高点击区，两行点击区域之间留8间隔。
4. 图表默认无重复标题、图表下方常驻说明或本期汇总，不预留说明文案间距；点图后才显示准确读数。
5. 记录列表默认5条预览，查看全部后20条一页按滚动追加，保留加载更多和吸顶收起；不设置添加/补记入口。
6. 简洁项目设置入口，底部删除项目。

累计采用阶梯线或准确折线，分布采用柱状图。双项分开看，不用双纵轴、圆环进度、能力等级或满屏数据卡。

## 6. 颜色、字体和图标

| 通用操作 | #285CDD |

图标使用原型自绘统一矢量图形；正式版整理为本地资源，不直接搬用Apple应用资源。SVG兼容性由目标微信环境验证，必要时从同一矢量源生成高清位图。

正式开发阶段重新打磨配色、图标与图片资产，目标为iPhone系统界面的细腻质感：渐变和明暗过渡克制，图形轮廓、笔画、光学尺寸与清晰度统一。当前原型的颜色圆点和示例图形用于表达交互，不作为最终资产定稿。

## 7. 动效、反馈和状态

按压反馈目标在100毫秒内可见。面板过渡约180～240毫秒，退出略快，不让记录等待动画。成功后更新累计并显示短暂撤销，不播放阻塞庆祝动画。

旧的底部反馈不能盖住下一次输入的操作区。记录面板、删除确认或项目配置打开时暂隐旧提示，计时继续；正式小程序用明确的输入上下文状态控制，不能直接复制原型的CSS :has选择器。

需要覆盖：空数据、双项缺失一项、首次预选、打卡关闭后重置、新增配置草稿恢复、保存中、保存失败、撤销、记录已删除、项目已删除、模式变更与数据读取异常。错误就地说明，保留已填内容。

较大字体可以改变卡片高度或列数；减少动效取消非必要运动；所有核心操作都有可见入口与读屏名称。浏览器原型不构成辅助功能或真机性能通过证明。

## 8. 原型与正式版的边界

原型使用HTML模拟微信界面与演示数据，参考日期固定为2026-11-24，刷新重置。它用于判断视觉、点击数、滑动体验与数据含义，不使用生产数据，不实现微信本地文件协议。

正式版不能直接复制浏览器的DOM、内联SVG、CSS mask、Pointer Events或字符串模板。视觉映射到原生小程序组件，数值与存储通过独立领域层实现；CSS效果和平台原生键盘需逐项验证。
