# 视觉与交互规范

## 方向与用语

以Apple macOS / iPhone系统界面的清晰层级、系统字体、克制配色、一致反馈和精细动效为目标。Android使用自身系统字体，不捆绑装饰字体，不搬用Apple应用资产。产品行为以[产品说明](../product/产品说明.md)为准，输入与兼容边界以[记录规范](../product/记录规范.md)为准。

产品名「北极星打卡」；固定用语「新增打卡」「打卡名称」「外观样式」「时间」「数量」「项目设置」。时间表示持续量，单位显示分钟／小时／天，历史秒单位显示秒；具体时刻的行标签为「时间」，辅助标签明确「具体时刻」。数量与记录条数分开。

名称输入与空名称预览均为「打卡名称」，不把占位写入配置。加载「正在加载…」，写入「保存中…」；成功为「已记录」「已保存修改」「已删除记录」「已撤销」。按钮不加句号，错误与风险保留准确含义，不把结果不确定或恢复旧副本简写为普通失败。输入限制不显示toast、底部错误或字数说明，备注计数保留。

## 导航与卡片

顶部栏固定在真实容器，背景不透明，保护状态栏、返回及微信胶囊。详情大标题滚出后中央显示打卡名称，回滚隐藏。首页整行搜索高至少44、圆角13、系统灰底，左放大镜，右侧按需显示清空，不默认抢焦点。

卡片四层：顶行图标与名称；当期主数字与次指标；全宽简图；底部全历史「共」与快速增量。顶行全宽44高只进详情，下方区域记录，两者相邻且独立。无目标、重复图名、额外首页模块或底部记录/统计标签。

## 项目配置

新增与设置统一预览、名称、外观样式和连续配置卡；设置页内容不再重复大标题。配置卡顺序为时间组、数量组、打卡频率、主要指标、快速打卡。标题16号系统字体400字重，前置18号本地线性图标；图标起点14，文字列42，参数与分割线都从42开始，不画到图标下方。

时间/数量各标题右侧开关，展开只影响显隐并保留内容。单位、范围、默认值按组显示；范围两个数值整体居右，短横线居中，不显示最小/最大文字，读屏保留边界含义；聚焦与默认值一致无框。单位分钟／小时／天与主要指标、频率均使用28高扁平选项，保留44高命中区。选中态同时用颜色与文字表达。

输入未完成可保存到新增草稿；创建/项目保存按钮保持可操作，仅写入中禁用。点击无效配置只滚动定位并聚焦对应字段，不显示限制错误。记录面板的未完成输入则禁用记录按钮。

## 记录面板

单项一个、双项两个细滑轨和圆形滑块，标签数值同一行，数值25号；控件高80，滑轨4高、圆块直径26、白色轻阴影，命中区44高。不画刻度、数字或中点标记，不显示滑动提示及不记功能。默认值按真实比例定位，拖动连续跟手，不重建面板。点数值原位编辑，保留滑块和面板高度，不增输入行或完成按钮。

日期收起时备注左、时钟与今天右，无加号；日期展开先日期/时间组件再备注。新建收起，编辑有备注自动展开且入口显示「备注」，手动折叠保留内容。备注框68高，长文本框内滚动；展开不自动弹键盘，不用自动测高二次改变面板，不重播整体入场动画。整行日期/时间均可打开系统选择器。

## 统计与列表

图表类型「累计／分布／日历」，分段视觉高32、字号13、白色选中轻阴影，点击区44，两组分段控件点击区间隔8。三类图表卡片统一462高，切换不移动下方记录列表。

累计/分布准确读数位于图底左侧固定24高区域，未选择保留空位；无常驻说明、重复标题或默认本期汇总。点选与取消不增高背景或改变列表位置。日历固定六行，日期触碰区至少44高、色块约34～36高；今天细轮廓，选中独立外圈，未来不可点。底部读数和右侧少—多图例共用34高单行，不额外留空行。

图表用屏幕外Canvas 2D生成缓存图片，由普通image随页面滚动，原生绘制层不参与滚动，滚动不重绘。日历与首页简图用普通视图。列表5条预览、全历史每批20条，随主页面滚动，手动加载和收起可操作。

## 动效与无障碍

按压约120ms，选项颜色160ms，外观选中180ms从0.92归位；配置/日期/备注展开180ms淡入并从上方4px归位，关闭立即隐藏。撤销提示220ms从下方8px淡入；原生page-container约200ms转场，系统转场独立于WXSS媒体查询。

整理晃动与×共用全尺寸父容器，拖动卡片跟手、停止自身晃动；邻卡220ms缓出，每张错开28ms、最多140ms。松手等待约380ms完成落位，再落实节点顺序，避免回旧位闪跳。减少动态效果时停止晃动及让位过渡。

成功反馈规格见产品说明；正式版彩纸与Emoji交替，分别由独立普通view/WXSS采样轨迹驱动，不逐帧setData，不新增Canvas覆盖层。浏览器使用本地固定版本tsParticles，原生适配不承诺逐像素或逐帧一致。

所有非必要动画提供减少动态效果降级；系统是否传入偏好须真机核验。按压目标100ms内可见，不用动画完成驱动存储提交。读屏完整说明名称、实际单位、数值、缺失及选择状态；不能只用颜色表达。较大字体允许调整卡高/列数，旧长内容仍可读。
