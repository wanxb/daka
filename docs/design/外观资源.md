# 外观与资源规范

## 正式资源

- 品牌图片：[北极星打卡](../../images/beijixing.png)，保留源文件，不作为已通过微信审核或所有尺寸适配的证明。
- 图标与配色唯一源：[project-appearance.json](../../shared/project-appearance.json)；图形源：[phosphor-regular.json](../../shared/phosphor-regular.json)。
- 正式运行资源：[miniprogram/assets](../../miniprogram/assets/README.md)；生成与维护方式：[shared说明](../../shared/README.md)。
- 成功勾形为自有独立SVG插画；普通界面统一Phosphor Regular，不混用其他图标库、Emoji或在线CDN。

## 外观选择

10种主题色：紫色、暖橙、蓝色、青绿、玫红、红色、草绿、湖蓝、靛蓝、棕色。浅色界面使用项目彩色主题，不提供灰色与深色主题。颜色与图标自由组合，不绑定业务含义。

15个图标：阅读、学习、健身、音乐、目标、跑步、睡眠、骑行、游泳、篮球、写作、语言、冥想、饮水、绘画。前5项默认可见；颜色与图标各默认显示5项，「更多外观」按5列展开，入口变「收起外观」。当前选择在扩展项时，收起替换第5个位置以保持可见；展开恢复完整固定顺序，不改变所选值。

展开状态仅属于页面，不入项目或草稿。32px色块与40px同心圆外圈置于44px点击区内，2px描边和内侧留白，避免outline超界裁切。图标保留上游256视框和Regular几何，不套旧描边宽度。

## 标识与兼容

旧项目、草稿外观标识仍可读：rope与walk映射到run，piano映射到music；别名不增加可选数量或额外SVG，不批量改写历史。非法标识在领域和资源组件边界拒绝，不直接拼接任意资源路径。映射以共享源及生成清单为准。

在根目录运行 `node scripts/sync-prototype-icons.mjs` 离线生成原型appearance.js、正式TS预设、WXSS和配色SVG，不手改生成文件。仅保留实际使用的图形/颜色组合，WXML出现新引用表达式时生成器应拒绝静默遗漏；生成器可清理已过期产物，不能删共享源或许可。
