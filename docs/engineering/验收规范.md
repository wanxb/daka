# 开发与验收规范

## 开发入口与边界

运行命令、Node版本、AppID和本机工具入口见[工程说明](../../README.md)。正式业务源码为miniprogram，浏览器原型仅为可重置演示，不能替代微信模拟器或真机。测试源码位于tests，属于长期维护的自动化检查，不作为临时资源删除。

本文件定义验收要求，不记录某次测试数量、截图、日志或发布结论。每次交付用当次命令结果说明已验证范围；未经设备验证不宣称手感、帧率、系统键盘或生命周期通过。

## 本地检查

- `npm run check`：类型、领域/仓储/控制器/工程边界测试与格式。
- `npm run check:native`：官方离线编译器检查WXML/WXSS语法，不等于模拟器运行与真机验收。
- `npm run preview:prototype`：启动只监听本机的原型服务；检查完整交互、多屏总览及所有本地脚本资源。
- 文档本地链接、HTML的iframe/src/href、预览服务白名单均指向现存资源；删除资源同步清理入口和引用。

## 业务与数据

| 范围 | 验收要点 |
|---|---|
| 初始化 | 仅真正新存档生成三个项目18条记录；含今天、休息日无零记录；跨年/闰月、并发、冷启、跨日、删空、旧项目/草稿/删除标记不追加 |
| 配置 | 时间/数量独立开关；范围整数中点、手改/切项/草稿恢复；全部关闭仅草稿；单位锁定；主指标顺序；快速打卡实际增量 |
| 输入 | 名称6字、备注100字/2次换行、单位4字、搜索20字；数量99,999、时间365天；负号/科学计数法/非法小数拒绝，临时空值和小数态保留，限制无toast |
| 历史兼容 | 旧长名称/备注、较大参数和旧秒单位可读；未改值不截断，1秒只改备注不被近似显示写回；过大默认值不可直接快速记录 |
| 范围记忆 | 整数精确输入成功后与记录原子记忆默认/扩展边界；关闭、失焦、失败、仅滑动、只改历史备注不更新；小数时间保留精确秒及原整数默认值 |
| 记录 | 同日多次相加，双项有效，历史缺失不补；日期1900-01-01至今天，时刻合法或空；保存时间不当发生时间；稳定ID重试幂等 |
| 频率 | 周一/跨年、大小月/闰年；7日/4周/6月含当前；缺字段按日、显式非法拒绝；改频率不改历史，详情默认/手动周期正确 |
| 统计 | 数量与条数分开，累计含期前基数、分布仅本期；补记/编辑/删除/撤销重算全部后续点；未来留白，点选不移动列表 |
| 日历 | 七列、实际占用的4／5／6周自适应行高、月份边界、同年同量同色、换单位不变档；空日/缺失/未来区分；选日、取消、换指标/月与全历史状态一致 |
| 列表 | 5条预览、全历史每批20条，无重漏；切周期/收起恢复预览，迟到加载不追加到另一项目 |
| 整理 | 长按不误记录；显示全部及恢复搜索；双向/跨行拖动、宽卡、边缘滚动与落位；完成才存，空白/后台放弃，已确认删除保留 |
| 反馈 | 确认写入后当天新记录播放，面板离场与刷新两种时序；快速/再次同强度、彩纸与Emoji交替；无效测量不推进、相邻Emoji素材更换和居中；撤销、滚动、导航及迟到回调清理，编辑/补记/失败不播放 |

## 仓储与故障注入

逐阶段覆盖写前失败、写后回调丢失、页/清单半写、回读、发布、重试与中断；确认记录、配置、初始化凭据不分离。未发布页不进入统计，同身份重试无重复，项目删除标记不能被旧清单或迟到命令复活。

覆盖配额不足、损坏清单/原页、未知新格式、旧命名空间迁移、过期修订、撤销跨后台、回收引用边界。不得将损坏当新存档初始化，不静默清空；恢复旧副本需明确用户确认，不能假称最后状态无损。

## 微信设备验收

375/390/430逻辑宽、系统大字体、旧长内容；iPhone与Android记录实际微信/基础库/机型。检查滑块跟手、横向与纵向手势、原位精确输入、日期/时刻选择器、键盘顶起、page-container返回及关闭丢弃输入。

检查固定导航、图片图表滚动层级、读数固定区域、读屏及44px命中区；减少动态效果、56片彩纸普通视图矩阵动画与16个Emoji平面散花、backdrop-filter/clip-path兼容。性能需实测，不以截图推断帧率。测试冷启、热启、后台、杀进程、升级、跨午夜及不同规模历史；当前整库内存加载不能宣称已有大容量性能保证。

手机预览、上传、审核、发布分别确认身份与操作范围。产品描述、名称/类目、隐私指引、账号备案按真实本地功能及平台当前要求核对；无业务网络接口不意味着免除小程序审核要求。

## 分享验收

覆盖单次、双项、累计基数、分布和整月日历口径；原始秒、记录单位快照、缺失值、长备注、简短票据和版本失效。验证关闭和过期回调清理图片，撤销不因预览或后台延长。真机核对iPhone/Android文字与图标解码、清晰度、相册同意/拒绝/设置后重试、分享取消及3.8.2以上朋友圈与低版本降级；不将模拟器或系统面板打开当作发送成功。
