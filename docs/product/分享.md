# 分享结果

分享只从已提交本地数据生成静态图片，不需要账号、云数据库或图片托管。点击分享后原地生成图片，直接打开微信原生图片分享面板，由用户自行选择发送、发布或保存；收到图片的小程序入口打开首页，不能通过本地项目ID读取原分享者的记录。

## 入口与内容

- 新建记录成功提示按「撤销」「分享」排列；普通和快速记录使用同一条已提交记录，编辑与删除提示不提供分享。历史列表每条仅保留编辑、删除入口。
- 详情累计、分布、日历右下角统一使用圆角翻页式「分享」文字入口，项目主题色约9%浅色衬底、可见44×25px、56×44px命中区、12px常规字重、项目主题色文字、读屏标签「分享当前统计」。入口固定贴合卡片右下角，左上12px、右下22px圆角；读数区域预留右侧空间，避免与文字重叠。项目名后不重复显示入口，不单独增加分享操作行。日历不显示少—多图例。
- 单次结果包含项目、发生日期、用户填写的具体时刻、本次各项投入；双项按项目主要指标排列，数量使用记录单位快照。右上角为「打卡成功」。有备注自动显示，没有备注不展示备注区域，不提供备注开关。
- 统计沿用当前指标、图表类型、周期与偏移；累计显示「当前累计」，日期范围在项目名下展示，图表下不再重复显示截至日期／本期新增说明，历史周期累计截至所选日期，不冒充今天总量，分布只统计本期，日历分享整月，与下方列表选日及全历史分页独立。注明准确日期范围，不把缺失量当作零。分布和日历图表下也不显示「按发生日期统计实际投入」。
- 单次海报不显示最近7天、已记录、当天合计或记录条数；卡片按单项／双项及备注内容适配高度。两类海报只保留项目、发生日期／统计范围、核心数值及实际备注／所选图表；不显示记录条数、投入日、口号、重复图表标题和少—多图例。采用近白底、项目主题色光晕与底部三层淡色弧面；单次使用轻量星光装饰，不绘制会被误解为进度的数据环。品牌在底部只出现一次。两类海报均使用实际品牌图标，源文件为 `images/beijixing.png`，144px派生资源为 `miniprogram/assets/brand.png` 与 `prototype/brand.png`。

## 直接分享与提交边界

正常流程不进入中间预览页。首页与详情页使用屏幕外Canvas生成原样海报，显示「正在生成」蒙层；完成后直接调用微信图片分享接口。连续点击不并发生成／打开面板，取消留在原页面，失败可选择重试或取消。页面离开后迟到绘制不能再弹面板；生成前后的数据版本不一致时拒绝使用旧图。

仅在旧客户端不存在图片分享接口时，保留保存图片的兼容预览页，使用短期内存票据接收快照；正文、备注、记录ID不进入可公开转发的路径。票据只可消费一次，应用重启、复制预览路径或无票据进入时显示失效，返回重新分享。分享页关闭普通页面转发菜单，图片消息附带的入口固定指向首页。

快照记录项目及其全部记录版本。直接生成前后及兼容预览返回／操作前重新校验，项目或相关记录被编辑、撤销、删除后旧预览失效。生成图片或打开原生面板不延长约5秒撤销期限；预览页按原截止时间提供撤销，返回首页时过期提示不恢复。已导出的静态图片不随之后的本地编辑更新。

原生Canvas 2D在屏幕外绘制，导出900像素宽本地PNG；预览与分享使用同一文件，页面滚动不重绘。备注换行增加海报高度，不覆盖统计和底部信息；超长旧备注超过画布容量时明确提示无法生成，不能静默截断备注。图标解码不兼容时保留项目名称并以北极星图形降级。无效及失败回调清理本次生成文件；成功打开原生面板的文件保留到下一次成功导出再替换，避免微信尚未读完图片时被删除，最多保留一份，不触碰业务数据文件。

## 微信与兼容

使用wx.showShareImageMenu打开原生图片分享面板，基础库3.8.2及以上支持面板内分享到朋友圈。接口存在不等于朋友圈能力存在；低版本明确保留保存图片后手动发布的路径。页面不声称已发送给朋友或已发布朋友圈，接口成功仅表示系统面板调用完成。

只有点击「保存图片」才请求相册权限。拒绝后保留预览，再次保存可选择去设置开启或返回。取消系统分享不是保存记录失败。图片生成失败允许重试，重复点击不并发打开多个系统面板，不影响原记录及累计。
