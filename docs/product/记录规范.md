# 时间与数量记录规范 v1

配套：[产品说明](产品说明.md)、[视觉交互](../design/视觉交互.md)。

界面上的持续时间单位统一显示为「分钟／小时／天」，旧记录的秒单位继续显示「秒」。卡片、累计、记录、图表读数、快速打卡、输入面板及配置选择统一使用完整名称；数字与单位分开呈现时，单位使用较小字号、常规字重及约4px间距。项目内部单位标识仍为「分／时／天／秒」，原始整数秒、换算和数量单位不变。

## 1. 指标与单位

首次使用的阅读（时间＋页）、跳绳（次）、运动（时间）卡片及近7天记录按[首次使用初始化方案](首次使用初始化.md)创建。模拟记录与手动记录使用相同字段、数量单位锁定规则及统计口径，不将休息日写为零值记录。

界面统一使用「时间」表示持续投入量，按项目选定的分钟/小时/天记录，底层使用整秒；「时间点」表示18:00等具体时刻，发生日期表示统计归属日。切换单位不改变原始秒数、统计口径或时间点的含义。

打卡类型在一张连续配置卡中按时间、数量纵向分组，标题右侧各有开关。新建默认时间开启并展开，数量关闭并折叠。可单独或同时启用，不提供组合按钮。两项均关闭时允许保留编辑草稿，创建/保存前要求至少启用一项。

时间单位默认分钟，可选小时、天，存储为正整数秒；数量为正整数，项目单位默认「次」，仅允许下列20个常用单位，不接受任意自定义文本、数字或英文缩写。日常记录直接使用项目单位，不逐次选择。

| 用途 | 允许的数量单位 |
|---|---|
| 通用计数 | 次、个、件、张 |
| 阅读与学习 | 页、字、本、篇、题、道 |
| 练习与课程 | 组、遍、首、节 |
| 运动与距离 | 圈、步、米、千米 |
| 饮水 | 杯、毫升 |

输入过程允许暂时为空或未填写完成；启用数量时，点击创建或保存设置，单位不在名单内则不保存，滚动定位并聚焦数量单位输入框，同时显示1500ms无图标、无蒙层轻提示「不是有效单位」。不展示有效范围，不增加常驻错误行，输入过程中不提示。去除首尾空白后按原字严格匹配，不将km等缩写自动转换为千米，不对已有自定义单位提供兼容豁免。保存层重复校验，绕过界面也不能写入非法单位。未启用数量时沿用隐藏配置规则，非法草稿不生成非法项目设置。实现名单由 `miniprogram/domain/input-limits.ts` 统一管理，浏览器原型镜像同一名单。

数量表示实际新增量，与记录条数分开。例如1000次跳绳加500次，是1500次、2条记录；阅读30页加20页，是50页、2条记录。不同项目和单位不合并累计。

单位在首次保存数量记录前可修改；保存过数量记录后固定，删除记录、撤销或关闭数量选项都不能解锁。记录保存单位快照，避免把历史1000次重新解释成1000页。

新记录填写所有启用指标的有效正值，不提供不记开关；历史缺失项仍保留为空，不补零或估算。发生日期默认今天；具体时刻与备注可以为空。

## 2. 范围与默认值

输入限制同时应用在界面与保存层，单次上限不限制长期累计：

界面静默约束输入：不接受非法字符、负数和超限值，保留最后允许的内容，不显示输入限制的底部错误、toast或「最多6字」等说明。打卡名称提示仅为「打卡名称」；备注右下角计数保留。打卡记录未填写完整时保存按钮不可用，精确数值结束编辑时恢复最后完整值。新增打卡与项目设置的主按钮保持可点击，配置缺项时点击只滚动定位并聚焦对应输入，不执行保存；持久化、冲突或恢复失败仍明确反馈。

| 输入项 | 限制 |
|---|---|
| 打卡名称 | 1～6个文字或完整Emoji，去除首尾空白，不能换行或包含控制字符；家庭、肤色职业、旗帜和键帽等组合Emoji各算1个 |
| 备注 | 最多100字，最多换行2次；输入框显示字数 |
| 单次数量 | 1～99,999的整数，不接受负数、小数、科学计数法 |
| 单次时间 | 大于0且不超过365天，即365天/8760时/525600分 |
| 时间精度 | 分钟、小时、天最多4位小数，必须能精确换算为整秒；秒只接收整数 |
| 范围与默认值 | 不超过对应单次上限；范围下限可为0，上限和默认值必须为正整数 |
| 数量单位 | 1～4字，不含空白或控制字符 |
| 搜索内容 | 最多20字 |
| 发生日期与时间点 | 1900-01-01至今天；时间点为00:00～23:59或空 |

旧版已经保存的长名称、长备注及较大数值不被截断、清空或拒绝读取。保持原值或只修改无关字段时可继续保存；新建及主动修改的值遵循新限制。旧默认值超过单次上限时，点击卡片打开输入面板，不能直接快速保存。切换时间单位保留原始配置文字，超出新单位对应365天上限时向内适配范围和整数默认值，不清空配置。

新增及项目设置使用「时间范围」「数量范围」，每行并排填写两个边界值，左小右大，以短横线分隔，不显示「最小」「最大」文字；读屏标签保留。数量组依次显示数量单位、数量范围、默认数量，不再配置标记点列表。上下限均为非负安全整数，最大值大于0，最小值不得大于最大值；相等时允许固定值范围。

修改任一有效边界后，默认值自动填写 `最小值 + floor((最大值 - 最小值) / 2)`。结果始终为整数，中点有小数时向下取整；结果为0时使用范围内最小有效正整数。手动默认值在结束编辑时向下取整并限制到当前范围边界，空值或非法值恢复整数中点。默认值可以手动改为范围内其他整数；之后再次改范围会重新计算，普通重绘、切换选项或恢复草稿不会覆盖手动值。

数量不提供步长配置，始终按1递增；时间滑动按所选单位的整数调节。滑块随手指连续移动，显示与保存的量转换为有效整数，松手时滑块对齐该值；精确输入的合法小数时间及未改动历史值继续保留原始整秒，不因重绘取整。

新建建议范围为时间1～120、单位分，数量1～100，默认分别60和50；用户在配置时按习惯调整。已填范围、默认值、单位及主指标在关闭某类型后隐藏并保留，重新开启恢复，保存配置也保留有效的隐藏设置。

滑块遵循当前范围，精确输入允许扩展范围。用户手动输入正整数并成功点击「记录」后，该项默认值同步为最终输入值；超过上限时提高上限，低于下限时降低下限，另一端保留。例如原范围1～30，录入35并记录后，范围变为1～35、默认值变为35，下次面板及项目设置均使用35，不重新计算中点。仅滑动且未使用数值输入时不修改项目默认值。

记录、范围和默认值在同一次本地事务中提交。输入、失焦或键盘完成不落库，关闭面板全部放弃；保存失败不允许只更新配置或只写入记录。小数时间继续保存精确整秒；需要扩展时边界向外取整，但保留原整数默认值。撤销记录不回滚已记住的范围和默认值。

修改范围不改历史值。编辑旧记录只改日期或备注时，不将历史数值写回默认值，也不扩展范围；手动改变数值时才应用上述输入规则。不能因为范围收窄而截断或取整历史记录。

时间组依次显示时间单位、时间范围、默认时间；时间单位默认分钟，可选小时/天。切换单位改变配置的输入单位及显示口径，范围数值与默认值保持用户配置，历史记录按同一真实秒数换算。录入的小数必须能换算为整秒，数量仍只允许正整数。历史换算除不尽时标≈，分/时最多显示4位小数，天最多显示8位小数以免短时间误显示为0，编辑未改数值时保留原始整秒，不把显示近似值写回。

## 3. 输入面板

项目名下方是滑块，单项一个、双项两个；左侧标签显示时间或数量，右侧数字旁显示分钟/小时/天或次/页等实际单位。点击数字后在原位置直接编辑，保留滑块与面板高度，不新增输入行或「完成」按钮；失焦或键盘完成退出数值编辑，只有底部「记录」保存。日期收起时，滑块下方同一行左侧为添加备注、右侧为带时钟图标的今天日期入口，不显示加号。两项独立展开，新建默认收起；编辑已有非空备注时自动展开，入口显示「备注」，不再显示「已填写」，仍支持点击收起、展开。日期展开时先显示日期/时间组件，再显示备注文字入口及其输入框，与点击顺序无关，收起不清空。

使用细滑轨与圆形滑块，不显示标尺刻度线、刻度数字或中点标签。标签左对齐、当前数值及单位右对齐。默认值按范围中的真实比例预选，不先从最左端动画滑过；精确输入750时，位置为范围内的真实比例。

备注提示使用「留下一点当时的感受」，长度上限只在右下角计数中显示。备注输入区固定68高，长内容在框内滚动；展开时一次确定面板高度，不通过原生自动测高二次调整。展开只展示输入区，点击输入框才进入输入，不自动弹出键盘；同一面板内展开、收起不重播面板入场动画。

拖动时只更新数值和滑轨填充，不重建面板，也不在每次移动中把滑块强制跳到整数位置。精确输入有效的越界数值时，本次面板的滑块范围随之扩展，项目配置仍等成功记录后才保存。边界均可到达，零边界仍不产生零量或空记录；原固定范围仍可通过数值输入扩展。

移除不记文案和功能，精确输入不得用清空绕过启用指标校验。历史缺失值不因展开备注或日期而补回默认值。面板不显示左右滑动提示。单个滑动控件原型高80，拖动区44高。

日期补充项标为「日期」，具体时刻标为「时间」，不显示选填；点击文字、空白处或原生输入均能打开系统选择器。具体时刻仍可为空，不用保存时间补齐。

只有点击「记录」才保存；滑动、松手、点击滑轨、键盘完成、展开备注均不提交。正常默认值合适时，卡片、记录两次点击完成。

键盘方向键与读屏可以按1调节滑块，Home/End选择端点；滑动触感、原生输入法及减少动效由微信真机阶段验证。

## 4. 项目配置与草稿

名称必填，空白预览名为「打卡名称」，颜色图标提供预设。时间、数量分组及底部主要指标、快速打卡两行连接在同一张配置卡片中，不保留首页突出或快速打卡的分区标题。类型选项只控制下方对应范围、默认值和单位的显隐，不清理填写内容，也不重置快速打卡开关或双项主指标。

新增打卡取消直接返回，无放弃确认；保留完整原始配置，包括暂不合法或尚未填完的内容，再次新增恢复。创建并成功保存项目后清空草稿。浏览器原型仅在当前页面内存中演示，刷新重置；正式版需要本地持久化。

已有项目设置仍在显式保存后生效，退出未保存修改时可继续编辑或放弃。切换类型不删除历史另一项数据，详情与编辑仍可查看。

创建按钮统一为「创建打卡」，仅在写入期间禁用，避免滚动到底部后面对无法操作的灰色按钮。点击时用准备后的配置校验：未填名称则滚回名称输入框并聚焦，缺少范围、默认值或数量单位时定位对应输入，两类均关闭时定位打卡类型开关，不显示底部错误或toast，不生成未完成的打卡。有效范围变更立即计算整数中点，手动默认值结束编辑或提交时夹入范围，不依赖先失焦再点按钮。切换时间单位时，仅将超出新单位绝对上限的参数收敛到上限，范围因此变化时重算中点；不改历史记录。

已关闭类型的原始输入在本次编辑和新建草稿中保持不变，再开启仍显示原内容。成功保存时保留其中完整有效的设置；未完成的隐藏组使用该项目上次保存的配置，新建则使用系统默认配置，不阻挡已启用类型。启用组缺名称、缺边界、范围倒置、空默认值或数量单位未填，以及两类均关闭时，点击创建/保存只定位对应输入，不执行保存。失败保留原始输入并恢复按钮，重试沿用同一项目标识。

## 5. 提交、补记与编辑

快速打卡默认关闭，标题右侧不显示「可选」。开启后按所有启用指标的默认值直接保存，卡片显示实际增量，例如「记30页」。详情图标只进详情；缺少有效配置时先打开面板。

详情不提供添加/补记入口；新记录从首页进入。需要修改发生日期时在普通打卡面板内确认日期与真实量，具体时刻不自动使用当前时刻。历史编辑保留原值、空项、日期、备注和单位，统一点「保存修改」。修改成功保留createdAt，更新updatedAt。

同一天可记录多次，数值相同也保留独立记录。单次提交使用稳定标识防重；短时双击快速打卡只提交一次，后续独立点击允许继续记录。

## 6. 校验与恢复

| 情况 | 行为 |
|---|---|
| 两种类型均未启用 | 允许暂存草稿；点击创建/保存定位类型开关，不写入项目 |
| 两项均无有效积累量 | 拒绝空记录 |
| 新记录有启用指标留空 | 保存按钮不可用，结束编辑时恢复最后完整数值；编辑历史原有空项时继续保留 |
| 0、负数或非法数字格式 | 拒绝保存；数量和秒只允许正整数，分钟/小时/天允许能精确换算为整秒的最多4位小数 |
| 范围倒置、缺一端或最大值不大于0 | 保留临时输入，点击项目创建/保存定位缺失输入，不写入项目，不显示错误文案 |
| 默认值越界、为小数或留空 | 结束编辑后取整数并限制到范围，空值恢复整数中点 |
| 已填一项非法、另一项有效 | 必须修正非法项，不能清空启用指标绕过校验 |
| 数量单位不在20项名单内或修改已固定单位 | 保留输入并拒绝保存，启用数量时定位数量单位输入框；无旧值兼容豁免 |
| 非法日期、未来日期或时间格式 | 选择器限定有效范围，非法改动不接受；新选日期为1900-01-01至今天，时间00:00～23:59 |
| 数值或累计超出安全整数 | 明确拒绝，防止溢出 |
| 本地写入失败 | 保留输入，重试沿用同一提交标识 |

新建或修改的项目名最多6字，备注最多100字且最多换行2次。项目名、备注、单位均作为普通文本，不执行为HTML或代码。

本次面板输入保存原值、单位、日期、备注、修订号与稳定提交标识，只在面板存续期间保留。遮罩、系统返回或Esc均丢弃未保存输入，不保存或恢复打卡草稿，也不显示继续上次填写入口。重新新建记录按项目默认值及今天打开，编辑历史记录按已保存原值打开。保存失败可在当前面板重试同一提交标识；项目配置已变化时提示重新打开，旧记录或项目已删除时拒绝迟到保存。

发生日期按用户确认的日历值保存，不经UTC换日。跨午夜后仍以界面上的日期为准；快速打卡按点击日期。保存时刻、时间点和时间分开，不推算结束时间或拆分跨日记录。

## 7. 统计与反馈

统计周期、频率、日历和成功反馈统一见[产品说明](产品说明.md)，避免同一规则在多处维护。发生日期为统计依据，时间与数量分别求和；补记、修改、删除及撤销须重算之后全部累计点。跨项目数量不合并。持久化成功后才更新累计与提示，新记录与单条删除约5秒可撤销，后台不暂停期限。

项目删除清理相关撤销，迟到回调不能复活项目。内部恢复不等于用户备份或换机同步。
