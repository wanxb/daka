# 基础设施层

`WechatFiles` 仅访问 `USER_DATA_PATH/yugong/v1/`，路径不接受项目名或备注。只把明确的文件不存在当成空库，权限与其他 IO 错误保留为错误。

`LocalRepository` 提供串行事务、不可变分片、双清单校验与回读。记录按项目/月分片，页目标 120KiB；草稿与撤销元数据随清单提交，避免跨存储事务。删除先确认标记，禁止旧清单或迟到命令复活项目。初始软容量 120MiB，不足时拒绝写入，不自动删历史。

当前快照在内存中保留整库，提交重新分桶并检查文件引用。分片持久化与 UI 分页已实现，磁盘按需加载及大容量真机性能尚未验收。
