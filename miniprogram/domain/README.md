# 领域模块

领域代码不依赖微信API、页面、应用命令或文件系统，可在Node中独立验证。

| 模块 | 责任与边界 |
|---|---|
| `types.ts` | 持久化契约、统一错误类型与空数据库结构 |
| `values.ts` | 整数、范围、稳定ID、整秒换算及数值格式化 |
| `project.ts` | 项目配置、指标启用顺序、数量单位锁与旧配置兼容 |
| `records.ts` | 记录校验、精确累计与稳定排序；未修改的历史原值不重写 |
| `calendar.ts` | 本地日历日期与跨日计算，独立于保存时间 |
| `input-limits.ts` | 统一输入上限与静默输入约束 |
| `statistics.ts`、`calendar-heatmap.ts`、`frequency.ts` | 从原始记录派生统计、日历和频率展示口径 |
| `appearance.ts` | 从shared生成的有限外观配置，不手改 |

`model.ts` 保留原有导出入口，避免调用方因拆分而改变行为；领域实现直接导入责任模块，不反向导入该入口，以免形成初始化循环。新功能按责任选择模块，不继续向入口堆积实现。
